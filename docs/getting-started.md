# MyPortfolio 上手指南

本文说明如何启动软件以及每个页面的使用方法。启动命令与常用命令见工程根目录 [README.md](../README.md)。

## 1. 启动

```powershell
cd myportfolio
npm install        # 首次运行
npm run dev:api    # 终端 1：后端 API，http://127.0.0.1:8787
npm run dev:web    # 终端 2：前端页面，http://127.0.0.1:5183
```

浏览器打开 http://127.0.0.1:5183/ 。首次启动使用示例数据（账户「招商证券」「天天基金」，组合「家庭总仓」，示例持仓与快照）。

启动前置检查（不满足会直接停止并给出原因）：运行环境版本、数据目录写权限、端口占用。

## 2. 账号与数据隔离

- 多账号使用，各账号数据相互隔离；跨账号访问会返回「无权访问该数据」。
- 口令不是明文保存；同一账号连续输错 5 次会锁定，并提示解锁时间。
- 会话有效期 12 小时、闲置 2 小时失效；退出登录后原会话立即不可用。

## 3. 账户与现金

路径：左侧菜单「账户与现金」。

**账户维护**

1. 填写账户名称、选择账户类型（券商 / 银行 / 基金平台 / 其他）与状态，点击「保存账户」。
2. 列表出现该账户后即生效；类型会以中文显示（如「券商」）。
3. 停用账户需二次确认；名称为空会提示「请输入账户名称」。

**现金账户**

1. 选择所属账户、填写账户名称、选择币种（CNY / USD / HKD / EUR / JPY）、填写初始余额。
2. 外币需填写汇率与汇率时间；手工填写的汇率会标记为「（手工）」。
3. 初始余额为负会被拒绝并提示「请输入不小于 0 的金额」；名称重复会提示「现金账户名称已存在」。
4. 顶部「现金折合人民币」按汇率折算合计，外币现金自动换算。

## 4. 交易与现金

路径：左侧菜单「交易与现金」。八类流水：买入、卖出、现金分红、红利再投、收入（工资）、支出、转账。

**买入**：选类型「买入」→ 填标的代码、数量、价格、手续费 → 选择付款现金账户 → 保存。
- 现金不足整笔拒绝（「现金账户余额不足」），现金与持仓都不会变化。
- 手续费口径可选计入成本或冲减收益；成本按移动加权平均结转。

**卖出**：选「卖出」→ 填数量与价格 → 选择收款现金账户。
- 卖出份额超过持仓会被拒绝（「卖出份额超过可用份额」）。
- 成功后显示已实现收益，持仓份额相应减少；清仓后该标的从持仓列表移除。

**分红**
- 现金分红：只增加现金账户余额，份额不变。
- 红利再投：需填写折算价格（缺失会提示「请填写大于 0 的折算价格」），成功后份额增加、单位成本摊薄。

**收入 / 支出**：金额为 0 或负数会被拒绝（「请输入大于 0 的金额」）；支出超过现金余额会被拒绝。

**转账**：选择转出与转入现金账户并填写金额。
- 生成两条关联流水（转出 / 转入），两边余额同步变化。
- 转出与转入为同一账户会被拒绝（「转出与转入账户不能相同」）；超出可用余额会被拒绝（「转账金额超过可用余额」）。

**修改与撤销**：删除流水后 5 分钟内可点「撤销删除」完整还原现金与持仓；超时后提示「撤销窗口已结束」。并发编辑同一流水时按版本号比对，过期提交返回「该流水已被修改，请选择覆盖或放弃」。

## 5. 持仓与组合

路径：左侧菜单「持仓与组合」。

- 顶部展示资产总额、成本、浮动盈亏与现金折合金额，并显示数据时间；使用缓存数据时会显示降级标识。
- 分类占比图只展示一级分类，颜色与分类一一对应，图例不含数值；分类明细展示各小项占比、所属一级分类占比与该分类总收益。
- 支持二级子分类管理（新增 / 删除），可覆盖单个持仓的成本价（覆盖后按覆盖值计算，不再随买入变动）。
- 分类筛选后明细条数与筛选结果一致。

## 6. 收益分析

路径：左侧菜单「收益分析」。

1. 选择统计维度：投资组合（可级联选择组合名称 → 一级分类 → 二级分类，子级默认「总计」）或账户。
2. 选择时间范围：近 6 个月 / 近 1 年 / 近 3 年 / 近 5 年 / 自定义（自定义可点选起止日期）。
3. 指标卡展示当前市值、累计投入、浮动盈亏、已实现盈亏与累计收益率；无流水时显示 0。
4. 收益曲线为市值与累计收益率双线；区间内有效快照少于 2 条时不绘制曲线，改为提示历史数据不足并保留当日指标。
5. 曲线基于前复权序列计算（含分红场景），单日涨跌幅超过阈值（默认 15%，可配置 5%–50%）的样本判定为异常：从曲线剔除并提示「已过滤异常样本 N 条」，原始数据仍可查看（异常样本以红色标记）。无异常时提示「未发现异常样本」。

> 自定义时间段的起止日期会真实参与快照过滤：区间外没有快照时会按「历史数据不足」处理。

## 7. 数据源

路径：左侧菜单「数据源」，共四个区域。

**数据源开关与优先级**
- 每行显示名称、类型（行情 / 净值 / 汇率）、优先级与启用状态，可「切换启用」。
- 至少需保留一个启用数据源；全部停用会被拒绝并提示「请至少启用一个数据源」，且拒绝不会改动现有配置。
- 服务端只按已保存的数据源配置发起请求，不接受界面提交的自定义地址（提交自定义地址返回「不支持自定义数据源地址」）。
- 「连通性检测」会显示最近检测时间与结果；失败时给出具体原因。

**刷新设置**
- 自动刷新周期默认 60 秒、最小 30 秒；小于 30 秒会回退默认并提示「自动刷新周期不得小于 30 秒，已回退默认值」。
- 「刷新场内行情」批量刷新全部场内标的：同一标的 30 秒内复用缓存并提示「数据未过期」；对上游请求全局间隔不小于 1 秒，触发限流会提示等待秒数。
- 场外基金不在批量刷新范围内，只支持「手动刷新基金净值」；当日净值未发布时保留上一净值并提示「当日净值未发布，展示上一净值」，不做盘中估值。

**最近刷新与错误日志**
- 显示最近刷新时间、更新成功 / 失败 / 缓存复用数量。
- 上游失败时保留最近一次成功数据并标注数据时间与失败原因；连续失败 3 次提示「已连续 3 次刷新失败，请检查本机网络与数据源配置」；失败与重试写入运行日志。

## 8. 备份、审计与主题

- 备份：按日生成备份文件，默认保留 7 天，超出保留期的备份自动清理。
- 审计：备份、现金账户与流水等关键操作记录操作人、动作、目标与变更前后值。
- 主题：默认浅色，可切换暗色，偏好保存在本机；传入非法主题会回退浅色并提示「主题取值无效，已恢复默认主题」。
