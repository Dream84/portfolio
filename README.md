# MyPortfolio

本地投资组合记录与分析工具。数据全部保存在本机，支持股票 / 基金 / 黄金 / 现金的持仓记录、交易流水、实时行情刷新与收益分析。

- 平台：仅 Windows 10 / 11
- 形态：本机运行的前端页面 + 本机 API 服务（同一台机器，无云端依赖）
- 存储：本机 sqlite 文件（首次启动自动建表并写入示例数据）

## 1. 环境要求

| 项 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 / 11 |
| Node.js | 18 及以上（本仓库开发环境为 20.18.1） |
| npm | 随 Node 安装（开发环境 10.8.2） |
| 磁盘 | 约 300 MB（依赖 + 数据 + 备份） |

## 2. 安装与启动

```powershell
# 1) 进入工程目录
cd myportfolio

# 2) 安装依赖（或运行 .\scripts\install.ps1）
npm install

# 3) 启动后端 API（占用 8787，需保持窗口打开）
npm run dev:api

# 4) 另开一个终端，启动前端页面（占用 5183）
npm run dev:web
```

启动成功后访问：

| 用途 | 地址 |
| --- | --- |
| 前端页面 | http://127.0.0.1:5183/ |
| 后端接口 | http://127.0.0.1:8787/api/ |

> 两个命令需要**同时运行**：`dev:api` 提供数据接口，`dev:web` 提供页面。关闭任一窗口对应服务即停止。
> 首次启动会自动建表并写入示例数据（账户：招商证券 / 天天基金，组合：家庭总仓）。

## 3. 常用命令

| 命令 | 作用 |
| --- | --- |
| `npm run dev:api` | 启动后端 API（8787） |
| `npm run dev:web` | 启动前端页面（5183） |
| `npm test` | 运行后端单元测试（vitest） |
| `npm run test:e2e` | 运行端到端测试（Playwright，使用本机 Edge / Chrome，不下载浏览器） |
| `npm run build` | 生产构建（校验依赖解析与编译） |

端到端测试前置条件：`dev:api` 与 `dev:web` 已在运行，否则用例会因连接被拒而失败。

## 4. 页面与功能

左侧菜单共五项，功能与使用步骤详见 [docs/getting-started.md](docs/getting-started.md)：

1. **持仓与组合** — 资产总额、分类占比、持仓明细、分类维护、成本覆盖
2. **收益分析** — 指标卡与收益曲线，支持时间范围与投资组合 / 账户维度
3. **账户与现金** — 账户维护（新增 / 停用）与现金账户（含外币与汇率折算）
4. **交易与现金** — 八类流水登记：买入、卖出、现金分红、红利再投、收入、支出、转账（转出 / 转入）
5. **数据源** — 数据源开关与优先级、连通性检测、刷新设置、最近刷新与错误日志

## 5. 数据与备份

- 数据文件位于工程内的数据目录；备份文件按日生成，默认保留 7 天（超过保留期自动清理）。
- 备份与关键操作写入审计记录（谁在何时改了什么，含变更前后值）。
- 数据口径：成本按移动加权平均；场外基金使用已公布净值（不做盘中估值）；外币现金按汇率折算为人民币。

## 6. 故障排查

| 现象 | 处理 |
| --- | --- |
| 页面打开是空白 / 报模块未定义 | 先确认 `dev:api` 与 `dev:web` 均在运行，然后 `Ctrl + F5` 强制刷新（开发期文件改动后浏览器可能持有旧模块） |
| `EADDRINUSE: address already in use 8787 / 5183` | 端口被占用：`Get-NetTCPConnection -LocalPort 8787 -State Listen` 找到 PID 后结束进程，或改用其它端口 |
| 接口返回「接口不存在」 | 后端进程是旧版本，重启 `dev:api` |
| 行情刷新失败 / 显示降级 | 上游不可用时按设计降级：保留最近一次成功数据并标注数据时间与失败原因；网络恢复后可重试 |
| 页面提示需登录 | 未登录状态下访问数据源页或触发刷新会被拦截，请先登录 |
